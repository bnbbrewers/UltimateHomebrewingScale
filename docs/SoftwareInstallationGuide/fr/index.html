Avant de commencer

Cinq choses à avoir sous la main. L'installation elle-même ne demande rien d'autre.

Votre UHS

Assemblé avec le guide d'installation matérielle, et un câble USB-C data : un câble de charge seule ne fonctionne pas.

Navigateur ordinateur

L'installation se fait dans Chrome ou Edge sur un ordinateur. Rien à télécharger.

Smartphone

Pour relier l'UHS à votre Wi-Fi : vous scannerez un QR code affiché sur son écran.

Accès Brewfather

Votre user ID et votre clé API Brewfather, trouvés dans les réglages de Brewfather, copiés sur votre téléphone.

Poids de calibration

L'assistant demande 0 g, 100 g, 500 g, 5 kg et 25 kg. Si les vôtres diffèrent, vous réglez leur poids réel à l'écran.

Étapes d'installation

Suivez les étapes dans l'ordre. L'UHS redémarre plusieurs fois en cours de route : c'est normal.

  1. Mettre l'UHS en mode installation

    Débranchez l'UHS. Maintenez le bouton BOOT / G0 au dos du Dial, branchez le câble USB-C à votre ordinateur en gardant le bouton appuyé, puis relâchez-le.

    Astuce : si le navigateur ne trouve rien à quoi se connecter à l'étape suivante, débranchez l'UHS et refaites cette étape.

  2. Installer l'application depuis cette page

    Cliquez sur le bouton ci-dessous, choisissez le port qui apparaît dans la liste et suivez les instructions du navigateur. Si l'effacement de l'appareil est proposé, acceptez-le pour une première installation propre.

    Compatibilité navigateur : utilisez Chrome ou Edge sur un ordinateur. L'installation ne fonctionne pas depuis un téléphone, ni depuis Safari ou Firefox.

  3. Redémarrer l'UHS

    Quand l'installation est terminée, débranchez le câble USB-C puis rebranchez-le.

  4. Configuration

    Lors d'une première installation, l'UHS ouvre de lui-même son écran de configuration.

    Comme il ne connaît pas encore votre Wi-Fi, il crée son propre réseau Wi-Fi, UHS-Setup, et affiche un QR code sur son écran rond.

    Rejoignez le Wi-Fi UHS-Setup avec votre smartphone, scannez le QR code, renseignez votre réseau Wi-Fi et vos identifiants API Brewfather, puis appuyez sur Save and reboot.

    Coupez les données mobiles/5G : désactivez-les sur le téléphone avant d'ouvrir le portail. Le Wi-Fi UHS-Setup n'a pas d'accès Internet, et la plupart des téléphones passent alors par la connexion mobile, qui ne peut pas joindre l'UHS. Réactivez-les une fois la configuration enregistrée.

    Chaque champ du portail est expliqué dans le guide d'utilisation. Revenez ici une fois l'UHS redémarré.

    Ouvrir le guide du portail

  5. Lancer l'assistant de calibration de la balance

    Après ce redémarrage, l'UHS se connecte à votre Wi-Fi. S'il affiche Problème Wi-Fi, appuyez sur OK et corrigez vos identifiants dans le portail, comme expliqué dans le dépannage.

    Une fois connecté, l'UHS ouvre de lui-même l'assistant de calibration de la balance. Il apprend à l'UHS ce que votre plateau mesure pour des poids connus, et ne se fait qu'une fois.

    1. Branchez le plateau quand l'UHS le demande, puis appuyez sur le bouton pour continuer.
    2. À chaque étape, posez le poids demandé sur le plateau.
    3. Si votre poids ne correspond pas exactement à la valeur demandée, tournez la molette pour régler son poids réel.
    4. Appuyez sur le bouton pour lancer la mesure, et gardez le poids immobile pendant le compte à rebours de 30 secondes.
    5. Recommencez pour chaque poids.

    La stabilité compte : posez le plateau sur une surface plane et n'y touchez pas pendant chaque mesure de 30 secondes. Plus la calibration est soignée, plus vos pesées sont justes.

  6. Terminer la calibration

    Après le dernier poids, l'UHS affiche Calibration terminée, OK pour redémarrer. Appuyez une fois sur le bouton.

    L'UHS redémarre une dernière fois et ouvre le launcher, la roue des apps. Il est prêt pour votre premier jour de brassage.

Dépannage rapide

La plupart des problèmes d'installation viennent du câble USB ou du mode installation. Les problèmes de portail sont traités dans le guide d'utilisation.

Le navigateur ne trouve rien à quoi se connecter
Utilisez un câble USB-C qui transmet les données, pas un câble de charge seule, et remettez l'UHS en mode installation avec le bouton BOOT / G0.
Les poids semblent incorrects
Vérifiez que le plateau est bien à plat et que rien ne le touche, puis tarez dans l'app Balance. Si l'écart persiste, la calibration est à refaire : réinstallez l'application depuis l'étape 2 en acceptant l'effacement de l'appareil.

Étape suivante : l'UHS est prêt. Le guide d'utilisation vous accompagne pendant votre jour de brassage : les commandes, puis chaque app tour à tour, de la pesée des malts au remplissage d'un fût.
