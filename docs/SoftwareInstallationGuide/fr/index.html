Configuration M5Stack Dial

Guide d'installation logicielle Ultimate Homebrewing Scale

Flashez le firmware personnalisé, connectez le Dial au Wi-Fi, renseignez vos identifiants Brewfather et calibrez la balance depuis l'assistant intégré.

Avant de commencer

Préparez le Dial, le matériel de pesée et les identifiants que vous renseignerez après le premier démarrage.

M5Stack Dial

Utilisez un câble USB-C data. Les câbles uniquement prévus pour la charge échouent souvent au flash.

Navigateur ordinateur

Le flash du firmware utilise Web Serial : utilisez Chrome ou Edge sur un ordinateur.

Smartphone

Utilisez-le après le flash pour rejoindre le Wi-Fi de configuration du Dial et scanner le QR code.

Accès Brewfather

Préparez sur votre téléphone votre user ID Brewfather et votre clé API pour pouvoir les coller dans le portail.

Poids de calibration

L'assistant utilise par défaut les points 0 g, 100 g, 500 g, 5000 g et 25000 g.

Étapes d'installation

Suivez les étapes dans l'ordre. Le Dial redémarrera plusieurs fois ; c'est normal.

1

Mettre le Dial en mode flash firmware

Débranchez l'USB-C. Maintenez le bouton arrière BOOT / G0, branchez le Dial à votre ordinateur en gardant le bouton appuyé, puis relâchez-le une fois la connexion USB établie.

Astuce : si le navigateur ne trouve aucun port série à l'étape suivante, débranchez le Dial et répétez cette séquence de mode flash.

Sur le M5Stack Dial, c'est la séquence de mode téléchargement de l'ESP32-S3 : maintenez G0 avant la mise sous tension, puis relâchez après l'alimentation. M5Stack le documente dans les notes du mode download du Dial.

2

Flasher le firmware depuis cette page

Cliquez sur le bouton d'installation, choisissez le port série du Dial et suivez les instructions du navigateur. Si l'effacement de l'appareil est proposé, choisissez l'option d'effacement pour une première installation propre.

Compatibilité navigateur : le flash web fonctionne depuis Chrome ou Edge sur ordinateur. Les navigateurs mobiles et Safari n'exposént généralement pas la connexion série requise.
3

Redémarrer après le flash

Quand le flash est terminé, débranchez et rebranchez l'USB-C, ou appuyez sur reset. Lors d'une installation neuve, l'application crée sa configuration par défaut et ouvre automatiquement l'écran de configuration.

Comme aucun identifiant Wi-Fi n'est encore enregistré, le Dial démarre son propre point d'accès de configuration et affiche un QR code sur l'écran rond.

4

Connecter votre smartphone au Wi-Fi de configuration du Dial

Sur votre smartphone, ouvrez les réglages Wi-Fi et rejoignez UHS-Setup. Le réseau de configuration n'a pas de mot de passe par défaut.

Restez connecté à ce Wi-Fi même si le téléphone indique qu'il n'a pas accès à Internet. Le téléphone doit seulement joindre le Dial en local.

Important : si la page de configuration ne s'ouvre pas, désactivez temporairement les données mobiles/5G. Certains téléphones préfèrent la connexion mobile quand le Wi-Fi UHS-Setup n'a pas d'accès Internet, ce qui empêche d'atteindre le Dial en local.
5

Scanner le QR code et ouvrir le portail de configuration

Scannez le QR code affiché sur le Dial. Il ouvre la page de configuration intégrée, normalement à http://192.168.4.1:8080/.

Si l'application appareil photo n'ouvre pas la page, gardez le téléphone connecté à UHS-Setup et saisissez l'adresse manuellement dans le navigateur.

6

Renseigner le Wi-Fi, Brewfather et les réglages de l'app

La page du portail est volontairement simple. Renseignez les valeurs ci-dessous, puis vérifiez-les avant de sauvegarder.

Champ Valeur à saisir
Langue Choisissez English ou French pour l'interface du Dial.
SSID Wi-Fi Saisissez le nom exact de votre réseau Wi-Fi 2,4 GHz.
Mot de passe Wi-Fi Saisissez le mot de passe de ce réseau Wi-Fi.
User ID Brewfather Collez votre user ID API Brewfather.
Clé API Brewfather Collez votre clé API Brewfather. Elle est masquée pendant la saisie.
Tolérance grains (g) Gardez la valeur par défaut sauf si vous voulez une tolérance de pesée plus large ou plus stricte.
Tolérance houblon (g) Gardez la valeur par défaut sauf si vous voulez une tolérance de pesée houblon plus large ou plus stricte.
Inertie spunding valve (ml) Gardez 200 ml par défaut ; ce paramètre servira au keg filler pour compenser l'inertie de fermeture.
Branche de mise à jour Gardez main pour les installations normales.
Logiciel de brassage Laissez brewfather sélectionné.
Sauvegarder et redémarrer : appuyez sur Save and reboot. Le Dial enregistre les identifiants Wi-Fi et les réglages de l'app, puis redémarre automatiquement.
7

Lancer l'assistant de calibration de la balance

Apres redémarrage, l'app cherche scale_calibration.json. Lors d'une installation neuve, ce fichier n'existe pas encore : le Dial ouvre donc automatiquement l'assistant de calibration.

  1. Connectez le matériel de pesée lorsque le Dial le demande, puis appuyez sur le bouton du Dial pour continuer.
  2. À chaque étape, placez le poids demandé sur la balance.
  3. Si votre poids physique ne correspond pas exactement à la valeur demandée, tournez le Dial pour ajuster la cible.
  4. Appuyez sur le bouton du Dial pour lancer la mesure et gardez le poids immobile pendant le compte à rebours de 30 secondes.
  5. Répétez l'opération pour tous les points de calibration.
La stabilité compte : placez la balance sur une surface plane et évitez de toucher la charge pendant chaque mesure de 30 secondes. De meilleures données de calibration donnent de meilleurs poids de brassage.
8

Redémarrer depuis la fin de l'assistant

Quand le dernier point de calibration est terminé, le Dial enregistre le fichier de calibration et affiche Calibration complete, OK to restart. Appuyez une fois sur le bouton du Dial.

L'application effectue un redémarrage logiciel. Au démarrage suivant, le Wi-Fi et la calibration sont enregistrés, le launcher s'ouvre normalement et la balance est prête à être utilisée avec les recettes Brewfather.

Dépannage rapide

La plupart des problèmes de configuration viennent du câble USB, du mode flash, du basculement Wi-Fi du téléphone ou d'un mouvement pendant la calibration.

Aucun port série n'apparaît Utilisez un câble USB-C compatible data et répétez la séquence de mode flash avec le bouton arrière BOOT / G0.
Le téléphone n'ouvre pas la page QR Reconnectez-vous à UHS-Setup, coupez temporairement les données mobiles/5G, puis ouvrez manuellement http://192.168.4.1:8080/.
Le Wi-Fi ne se connecté pas après sauvegarde Rouvrez le portail de configuration depuis Settings, vérifiez l'orthographe du SSID et confirmez qu'il s'agit d'un réseau 2,4 GHz.
Les poids semblent incorrects Relancez l'assistant de calibration et laissez la balance vide pour le point 0 g.
