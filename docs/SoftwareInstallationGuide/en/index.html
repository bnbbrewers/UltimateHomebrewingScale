Before You Start

Five things to have at hand. The installation itself needs nothing else.

Your UHS

Assembled with the Hardware Installation Guide, and a USB-C data cable: a charge-only cable will not work.

Desktop Browser

The installation runs in Chrome or Edge on a computer. There is nothing to download.

Smartphone

To connect UHS to your Wi-Fi: you will scan a QR code shown on its screen.

Brewfather Access

Your Brewfather API user ID and API key, found in the Brewfather settings, copied on your phone.

Calibration Weights

The wizard asks for 0 g, 100 g, 500 g, 5 kg and 25 kg. If yours differ, you set their real weight on screen.

Installation Steps

Follow the steps in order. UHS restarts several times along the way: that is normal.

  1. Put UHS in installation mode

    Unplug UHS. Hold the BOOT / G0 button on the back of the Dial, plug the USB-C cable into your computer while keeping the button pressed, then release it.

    Tip: if the browser finds nothing to connect to in the next step, unplug UHS and do this step again.

  2. Install the application from this page

    Click the button below, choose the port that appears in the list, and follow the browser prompts. When asked whether to erase the device, choose to erase it for a clean first install.

    Browser support: use Chrome or Edge on a computer. Installation does not work from a phone, nor from Safari or Firefox.

  3. Restart UHS

    When the installation is finished, unplug the USB-C cable and plug it back in.

  4. Configuration

    On a first installation, UHS opens its setup screen by itself.

    As it does not know your Wi-Fi yet, it creates its own Wi-Fi network, UHS-Setup, and shows a QR code on its round screen.

    Join the UHS-Setup Wi-Fi with your smartphone, scan the QR code, fill in your Wi-Fi network and your Brewfather API credentials, then tap Save and reboot.

    Turn off mobile data/5G: switch it off on the phone before opening the portal. The UHS-Setup Wi-Fi has no internet access, so most phones fall back to mobile data, which cannot reach UHS. Turn it back on once the settings are saved.

    Every portal field is explained in the User Guide. Come back here once UHS has restarted.

    Open the setup portal guide

  5. Run the scale calibration wizard

    After this restart, UHS connects to your Wi-Fi. If it shows Wi-Fi problem, press OK and correct your credentials in the portal, as explained in Troubleshooting.

    Once connected, UHS opens the scale calibration wizard by itself. It teaches UHS what your platform reads for known weights, and it is only done once.

    1. Connect the platform when UHS asks for it, then press the button to continue.
    2. For each step, place the requested weight on the platform.
    3. If your weight is not exactly the requested value, turn the dial to set its real weight.
    4. Press the button to start measuring, and keep the weight still for the 30-second countdown.
    5. Repeat for every weight.

    Stability matters: put the platform on a flat surface and do not touch it during each 30-second measurement. The more careful the calibration, the more accurate your weighings.

  6. Finish the calibration

    After the last weight, UHS shows Calibration complete, OK to restart. Press the button once.

    UHS restarts one last time and opens the launcher, the wheel of apps. It is ready for your first brew day.

Quick Troubleshooting

Most installation problems come from the USB cable or from the installation mode. Setup portal problems are covered in the User Guide.

The browser finds nothing to connect to
Use a USB-C cable that carries data, not a charge-only one, and put UHS back in installation mode with the BOOT / G0 button.
Weights look wrong
Check that the platform sits flat and that nothing touches it, then tare in the Scale app. If the error remains, the calibration has to be redone: install the application again from step 2, choosing to erase the device.
